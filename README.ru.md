Читайте мангу на своём языке — прямо в браузере.

comic-translate-4-free переводит страницы манги и комиксов автоматически, пока вы читаете. Он понимает японский, английский, упрощённый и традиционный китайский (с автоопределением) и переводит на 114 языков. Откройте страницу — и переведённая версия заменит исходное изображение прямо на его месте: облачка речи наполнятся вашим языком.

## ✨ Возможности

- **Автоматический перевод** — откройте страницу манги на разрешённом сайте, и переведённая версия появится на месте оригинала, нажимать кнопку не нужно.
- **Перевод любого изображения по правому клику** — выберите «Send to comic-translate-4-free», чтобы перевести конкретную картинку, даже если она меньше минимального размера.
- **114 языков перевода** через Google Translate, Azure Translator или ваш собственный локальный сервер LM Studio.
- **Автоопределение исходного языка** — японский, английский, упрощённый/традиционный китайский распознаются автоматически по тексту, полученному из OCR.
- **Поддержка длинных стрипов / вебтунов** — высокие страницы обрабатываются перекрывающимися сегментами, чтобы текст оставался чётким.
- **16 языков интерфейса** — интерфейс расширения следует языковой настройке вашего браузера.

### 🔒 Конфиденциальность

- **ИИ работает на вашем компьютере.** Детекция облачков, OCR и инпейнтинг выполняются локально в вашем браузере через WebAssembly. Ваши страницы никогда не покидают устройство.
- **Отправляется только переводимый текст** — сервису перевода, который вы выбрали (Google / Azure / ваш локальный LM Studio), уходят только извлечённые строки.
- **Без учётной записи, без слежки, без телеметрии.** Все настройки и загруженные модели хранятся в локальном хранилище вашего браузера.

## 🚀 Установка

**Chrome / Edge / Brave:**

[**Установить из Chrome Web Store**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj) — один клик, автоматические обновления.

**Firefox:** скачайте Firefox-архив из [Releases](https://github.com/jameslee0623/comic-translate-4-free/releases), затем перейдите в `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → выберите `manifest.json`. (Временные дополнения выгружаются при перезапуске; подписанный листинг AMO в разработке.)

После установки откройте страницу настроек и один раз нажмите **Download all models** (~350 МБ: детектор, OCR, инпейнтер). Они кэшируются в браузере и проверяются по размеру в байтах.

![Скачивание моделей со страницы настроек](docs/images/options-models.png)

## 💡 Как пользоваться

1. **Сначала разрешите сайт** — нажмите на значок расширения и нажмите **Allow this site** (или включите **ALLOW ALL SITES**). Перевод работает только там, где вы дали разрешение.

   ![Разрешить сайт из всплывающего окна](docs/images/popup.png)

2. **Обновите страницу манги** — перевод начнётся автоматически при загрузке страницы. Плашка в правом верхнем углу показывает живой прогресс (Capturing → Detecting → OCR → …).
3. **Готово** — картинка страницы заменяется на месте переведённой версией.

**Советы:**
- Щёлкните правой кнопкой по любому изображению → **Send to comic-translate-4-free**, чтобы перевести только эту картинку.

  ![Отправить изображение через контекстное меню](docs/images/right-click.png)

- Если сайт блокирует скачивание (HTTP 403), расширение автоматически повторит попытку через фоновую вкладку.
- Выберите движок перевода в настройках: Google (бесплатно, без ключа), Azure Translator (ключи получаются ниже — 2 млн символов/мес бесплатно) или LM Studio (локальный сервер).
- Включите **Debug mode** в настройках, чтобы просматривать каждый этап конвейера.

## 🔑 Получение учётной записи Microsoft Azure

Чтобы использовать Azure Translator в качестве движка перевода:

1. Создайте учётную запись Microsoft/hotmail/Azure или войдите в неё
2. Создайте подписку Azure
3. Создайте ресурс Azure Translator
4. Выберите тарифный план F0 (Free) — 2 миллиона символов/мес, срок не ограничен
5. Управление ресурсом → Ключи и конечная точка → скопируйте **KEY 1** и **Location/Region**
6. Вставьте их на страницу настроек расширения

## ⚠️ Известные проблемы

- **Корейский OCR пока отсутствует** — исходные языки: японский, английский и упрощённый/традиционный китайский. (Корейский остаётся доступным как язык перевода.)
- **Одна картинка на страницу** для автоперевода (главное изображение страницы). Используйте правый клик → Send, чтобы перевести остальные.
- **Длинные сессии** — перевод десятков изображений за одну сессию может аварийно завершить браузер. Если это случится, очистите кэш страниц в настройках.
- **Firefox** — модели работают на фоновой странице (без offscreen-документов), разделяя память со всем остальным. Если видите ошибку «no available backend found», перезапустите браузер.
- Google Translate использует неофициальный бесплатный эндпоинт и может подвергаться ограничению частоты запросов.
