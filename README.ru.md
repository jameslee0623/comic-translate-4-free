# comic-translate-4-free

**Language:** [English](README.md) · [हिन्दी](README.hi.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [Русский](README.ru.md)

Перевод страниц манги и комиксов прямо в браузере. Весь конвейер работает локально:
детекция облачков и текста (RT-DETR-v2), OCR (Baberu для японского/английского/китайского),
удаление текста
с помощью инпейнтинга LaMa, перевод (Google / Azure / локальная LLM) и вписанный
повторный рендеринг в исходные речевые облачка.

Интерфейс расширения следует языковой настройке вашего браузера (английский, японский,
корейский, китайский упрощённый/традиционный, хинди, испанский, арабский, французский, русский).

Этот проект вдохновлён [ogkalu2/comic-translate](https://github.com/ogkalu2/comic-translate).

## Установка

**Chrome (рекомендуется):** установка из
[**Chrome Web Store**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj)
— один клик, автоматические обновления.

**Ручная установка (Chrome):** скачайте zip из Releases выше и распакуйте его,
затем `chrome://extensions` → включите **Режим разработчика** →
**Загрузить распакованное расширение** → выберите распакованную папку.

**Firefox:** `about:debugging#/runtime/this-firefox` → **Загрузить временное
дополнение** → откройте распакованную папку и выберите `manifest.json`. (Временные
дополнения работают до перезапуска Firefox. Для постоянной установки сборка должна
быть подписана на addons.mozilla.org. Работаем над подписанной сборкой для обычного Firefox.)

Затем один раз скачайте модели со страницы настроек — одна кнопка
**Скачать все модели** загружает всё (детектор, модели OCR,
инпейнтер, всего ~350 МБ). Они кэшируются в браузере (IndexedDB) и больше
не скачиваются. Размер каждого файла в байтах проверяется после скачивания;
усечённый или неверный файл помечается значком ⚠ и может быть скачан заново.

![Скачивание моделей со страницы настроек](docs/images/options-models.png)

## Использование

1. **Сначала разрешите сайт** — перевод работает только на сайтах, которые вы явно
   разрешили. Нажмите на значок расширения и нажмите **Разрешить этот сайт**
   (или добавьте хосты в настройках, или включите **РАЗРЕШИТЬ ВСЕ САЙТЫ**, чтобы пропустить
   этот шаг везде). Это жёсткое ограничение: конвейер отказывается
   работать где-либо ещё.

   ![Всплывающее окно расширения](docs/images/popup.png)

2. Откройте страницу манги на разрешённом сайте — перевод начнётся
   автоматически, как только страница загрузится, без нажатия кнопки
   (отключается в настройках в пункте «Автоперевод при загрузке страницы»).
   При первом использовании на сайте Chrome запрашивает разовое разрешение, чтобы
   расширение могло скачать изображение страницы в полном разрешении.
3. Плашка статуса в правом верхнем углу страницы показывает живой прогресс
   (Захват → Детекция → OCR → …). Когда готово, собственное изображение страницы
   заменяется на месте переведённой версией — исходный текст закрашен
   инпейнтингом, перевод вписан обратно в облачка.

Чтобы перевести одну конкретную картинку вместо главного изображения страницы,
щёлкните по ней правой кнопкой и выберите **Отправить в comic-translate-4-free**. Это отправляет
именно это изображение через конвейер — даже если оно меньше
минимального размера изображения — и всё равно заменяет его на месте. Пункт меню
появляется только на разрешённых вами сайтах.

Если сервер изображений отклоняет скачивание (HTTP 403, например защита от ботов
Cloudflare), расширение автоматически открывает изображение в фоновой
вкладке — там оно same-origin, поэтому картинка читается напрямую без
скачивания — переводит её, закрывает вкладку и заменяет картинку на вашей
странице на месте.

   ![Контекстное меню](docs/images/right-click.png)

Вход конвейера — самое большое изображение страницы, ограниченное настройкой
минимального размера изображения (по умолчанию 500px): меньшие картинки пропускаются
с понятной ошибкой. Расширение читает собственное изображение страницы напрямую —
оно никогда не делает скриншот веб-страницы.

**Кэш страниц:** страницы, к которым вы возвращаетесь в той же сессии браузера, мгновенно загружаются
из временного кэша на диске (перевод 10–40 изображений за одну сессию может
уронить браузер, при этом все изображения в кэше будут потеряны. Не забывайте очищать
кэш вручную). Кэш автоматически очищается при закрытии браузера
и никогда не используется в окнах инкогнито.

**Настройки** (нажмите на значок → Настройки): доступ к сайтам, автоперевод при
загрузке страницы, исходный язык (включая **Автоопределение**, которое распознаёт
японский / английский / китайский упрощённый / традиционный по распознанному OCR тексту)
и целевой язык, движок перевода (Google бесплатно / Azure
Translator / LM Studio), кнопки проверки соединения для Azure и LM Studio,
порог детекции, минимальный размер изображения (по умолчанию 500px — меньшие захваты
пропускаются), размеры шрифта, режим отладки и управление кэшем переведённых страниц.

### Получение учётной записи Microsoft Azure

1. Создайте/войдите в учётную запись Microsoft/hotmail/Azure
2. Создайте подписку Azure
3. Создайте ресурс Azure Translator
4. Выберите тарифный план F0 (бесплатный)
5. Управление ресурсом → Ключи и конечная точка → скопируйте **KEY 1** и **Расположение/регион**

Microsoft в настоящее время заявляет, что бесплатный уровень F0 для Translator — это 2 миллиона символов в месяц без ограничения срока.

### LM Studio

Запустите LM Studio с включённым локальным сервером (по умолчанию
`http://127.0.0.1:1234`). Выберите **LM Studio (локальный сервер)** в качестве движка перевода
в настройках, задайте URL сервера и вариант API — **LM Studio REST API v1**
(отправляет на `/api/v1/chat`) или **OpenAI-совместимый** (отправляет на
`/v1/chat/completions`) — затем нажмите **Проверить соединение с LM Studio**, чтобы
убедиться. Загруженная модель определяется автоматически и запоминается, поэтому
поля для имени модели нет.

## Сборка из исходников

Без бандлера, без npm install — исходники и есть расширение. Требования:
`bash`, `python3`, `rsync`, `zip` и `node` (используется только для проверки синтаксиса).

```bash
git clone https://github.com/jameslee0623/comic-translate-4-free.git
cd comic-translate-4-free
./build.sh
```

Это записывает три zip в `dist/` (плюс копию объединённого zip для
удобства):

- `comic-translate-4-free-v<version>-<build>.zip` — объединённый, `chrome/` и
  `firefox/` рядом, готов к загрузке распакованным (Chrome) или как временное
  дополнение (Firefox) согласно разделу «Установка» выше
- `comic-translate-4-free-v<version>-<build>-chrome.zip` — только сборка для Chrome,
  в layout для отправки в магазин
- `comic-translate-4-free-v<version>-<build>-firefox.zip` — только сборка для Firefox,
  в layout для отправки в магазин

Штамп `<build>` берётся из константы `BUILD` в `src/shared/version.js`
(показан в подвалах всплывающего окна и страницы настроек, вшит в ключ кэша страниц).
Увеличьте его перед сборкой, если хотите уникальный штамп в имени файла и подвале
интерфейса — иначе ваша сборка неотличима от выпущенной с тем же штампом.

На страницу расширение отправляет один батчированный запрос:

```
POST {server}/chat/completions
{
  "messages": [
    { "role": "user",
      "content": "Translate the following 9 text(s) from Japanese to Chinese (Traditional):\n[\"…\",\"…\"]" }
  ],
  "temperature": 0,
  "texts": ["…", "…"],
  "target": "zh-TW",
  "source": "ja"
}
```

Ожидается, что модель ответит JSON-массивом переведённых строк —
по одной на каждый входной текст, в том же порядке. Голый `[...]` внутри более длинного ответа
принимается; по одному переводу на строку — крайний запасной вариант.

## Режим отладки

Включите **Режим отладки** в настройках, и вывод каждого этапа конвейера появится в
инспекторе боковой панели: захваченное изображение, рамки детекции, текстовые блоки, OCR
кропы + распознавания, маска инпейнтинга, страница после инпейнтинга и переводы.

## Архитектура

```
popup / settings (src/ui)
      │ chrome.runtime messages
      ▼
background — оркестрация, захват, блоки, маска, API перевода,
             вывод отладки
  ├─ Chrome: service worker + offscreen-документ (src/offscreen), хостящий
  │  ВСЕ сессии onnxruntime-web (скачивания идут там, чтобы загрузка на 197 МБ
  │  пережила остановку SW)
  └─ Firefox: фоновая страница (src/background/background.html), хостящая те же
     сессии в процессе (в Firefox нет offscreen-документов)
└── content-скрипт (src/content) — канвас оверлея + рендерер текста + панель отладки
```

Модели (Hugging Face, скачиваются по требованию):
- `ogkalu/comic-text-and-bubble-detector` → `detector-v4-s_int8.onnx`
- `genshiai-daichi/baberu-ocr` → `vision_int4.onnx`, `decoder_prefill_int8.onnx`,
  `decoder_step_int8.onnx` (японский, английский, китайский упрощённый/традиционный)
- `ogkalu/lama-manga-onnx-dynamic` → `lama-manga-dynamic.onnx`

Этапы конвейера: capture → detect → blocks → OCR → mask → inpaint →
translate → render. Детекция работает на 640×640; захват масштабируется по площади
(бюджет 6.5 Мп), чтобы длинные стрипы сохраняли полное разрешение, а страницы с
соотношением сторон экстремальнее 4:1 обрабатываются перекрывающимися сегментами 2:1.

**Конвейер Chrome vs Firefox:** обе сборки выполняют перевод параллельно с
mask/inpaint после OCR. Chrome делает это через Promise.all — ML-сессии
живут в offscreen-документе в собственном потоке, поэтому этапы действительно
перекрываются. Firefox выполняет перевод в Web Worker (собственный поток), пока
mask → inpaint идёт в главном потоке — сетевой ввод-вывод воркера не
блокируется, когда WASM-инпейнтинг занимает главный поток.

## Известные ограничения

- Пока не найден хороший OCR для корейского — исходные языки ограничены японским,
  английским и китайским упрощённым/традиционным.
- Автоперевод обрабатывает одну картинку на страницу (главное изображение страницы).
  Чтобы перевести любую другую картинку на странице, щёлкните по ней правой кнопкой и выберите
  **Отправить в comic-translate-4-free**.
- Некоторые хосты изображений блокируют автоматизированные скачивания (HTTP 403, например защита от ботов
  Cloudflare), хотя сама страница загружает изображение нормально.
  **Отправить в comic-translate-4-free** по правому клику обходит это через фоновую
  вкладку; автоперевод на таких сайтах может завершаться ошибкой 403.
  Эта блокировка может быть непостоянной.
- Firefox: модели ИИ работают внутри фоновой страницы браузера (в Firefox нет
  offscreen-документов), разделяя память со всем остальным. На очень больших
  страницах или при долгих сессиях движку может не хватить памяти, и он сообщит
  "no available backend found". Перезапуск браузера освобождает память; в Chrome
  этой проблемы нет, так как модели работают в отдельном процессе.
- Chrome: перевод десятков изображений за одну сессию может уронить браузер
  (наблюдалось примерно при 35 закэшированных изображениях).
- Кэш страниц ограничен сессией: он стирается при запуске браузера, поэтому
  после перезапуска (включая после падения) повторно отправленные изображения проходят полный
  конвейер заново вместо попадания в кэш.
- Движок перевода Google использует неофициальную конечную точку `translate.googleapis.com`
  и может подвергаться ограничению частоты запросов.
- Вертикальный текст рендерится для высоких CJK-блоков; SFX / текст вне облачков
  использует собственный текстовый блок.
