## ✨ خصوصیات

- خودکار ترجمہ — اجازت یافتہ سائٹ پر مانگا صفحہ کھولیں اور ترجمہ شدہ ورژن وہیں ظاہر ہوگا، کسی بٹن کو دبانے کی ضرورت نہیں۔
- کسی بھی تصویر پر رائٹ کلک کریں — کسی مخصوص تصویر کا ترجمہ کرنے کے لیے "Send to comic-translate-4-free" منتخب کریں، چاہے وہ کم از کم سائز سے چھوٹی ہو۔
- Google Translate، Azure Translator، یا آپ کے اپنے مقامی LM Studio سرور کے ذریعے 114 ہدف زبانیں۔
- ماخذ زبان کی خودکار شناخت — OCR شدہ متن سے جاپانی، انگریزی، سادہ/روایتی چینی خودکار طور پر پہچانی جاتی ہے۔
- لمبی پٹی / ویب ٹون سپورٹ — لمبے صفحات اوورلیپنگ حصوں میں پروسیس کیے جاتے ہیں تاکہ متن واضح رہے۔
- 17 UI زبانیں — ایکسٹینشن کا انٹرفیس آپ کے براؤزر کی زبان کی ترتیب پر عمل کرتا ہے۔

### 🔒 رازداری

- AI آپ کی مشین پر چلتا ہے۔ بلبلے کی شناخت، OCR اور inpainting سب آپ کے براؤزر میں مقامی طور پر چلتے ہیں۔ شناخت اور OCR WebAssembly کے ذریعے چلتے ہیں۔ Inpainting Chrome میں GPU پر چلتا ہے (WebAssembly فال بیک کے ساتھ)، اور Firefox میں WebAssembly کے ذریعے۔ آپ کے صفحات کبھی آپ کا آلہ نہیں چھوڑتے۔
- صرف ترجمہ شدہ متن باہر بھیجا جاتا ہے — صرف نکالی گئی سٹرنگز آپ کی منتخب کردہ ترجمہ سروس (Google / Azure / آپ کا مقامی LM Studio) تک جاتی ہیں۔
- کوئی اکاؤنٹ نہیں، کوئی ٹریکنگ نہیں، کوئی ٹیلی میٹری نہیں۔ تمام ترتیبات اور کیش شدہ ماڈل آپ کے براؤزر کی مقامی اسٹوریج میں رہتے ہیں۔

## 💡 استعمال کا طریقہ

1. پہلے سائٹ کو اجازت دیں — ایکسٹینشن آئیکن پر کلک کریں اور اس سائٹ کو اجازت دیں دبائیں (یا تمام سائٹس کو اجازت دیں فعال کریں)۔ ترجمہ صرف وہیں چلتا ہے جہاں آپ نے اجازت دی ہے۔

   ![پاپ اپ سے سائٹ کو اجازت دیں](../docs/images/popup.png)

2. مانگا صفحہ دوبارہ لوڈ کریں — صفحہ لوڈ ہوتے ہی یہ خودکار طور پر ترجمہ شروع کر دیتا ہے۔ اوپر دائیں جانب ایک پل لائیو پیش رفت دکھاتی ہے (Capturing → Detecting → OCR → …)۔
3. ہو گیا — صفحے کی تصویر وہیں ترجمہ شدہ ورژن سے بدل جاتی ہے۔

ٹپس:
- کسی بھی تصویر پر رائٹ کلک کریں → صرف اس تصویر کا ترجمہ کرنے کے لیے Send to comic-translate-4-free۔

  ![تصویر بھیجنے کے لیے رائٹ کلک کریں](../docs/images/right-click.png)

- اگر کوئی سائٹ ڈاؤن لوڈ بلاک کرتی ہے (HTTP 403)، ایکسٹینشن بیک گراؤنڈ ٹیب کے ذریعے خودکار طور پر دوبارہ کوشش کرتا ہے۔
- ترتیبات میں اپنا ترجمہ انجن منتخب کریں: Google (مفت، کوئی کلید نہیں)، Azure Translator (نیچے کلیدوں کے لیے درخواست دیں — 2M حروف/ماہ مفت)، یا LM Studio (مقامی سرور)۔
- پائپ لائن کے ہر مرحلے کی جانچ کے لیے ترتیبات میں ڈیبگ موڈ (مرحلہ انسپکٹر) فعال کریں۔

## 🔑 Microsoft Azure اکاؤنٹ کے لیے درخواست دیں

Azure Translator کو ترجمہ انجن کے طور پر استعمال کرنے کے لیے:

1. Microsoft/hotmail/Azure اکاؤنٹ بنائیں/سائن ان کریں
2. Azure سبسکرپشن بنائیں
3. Azure Translator ریسورس بنائیں
4. F0 (مفت) قیمت کا درجہ منتخب کریں — 2 ملین حروف/ماہ، کبھی ختم نہیں ہوتا
5. Resource Management → Keys and Endpoint → KEY 1 اور Location/Region کاپی کریں
6. انہیں ایکسٹینشن کے ترتیبات صفحے میں پیسٹ کریں

## ⚠️ معلوم مسائل

- ابھی تک کورین OCR نہیں — ماخذ زبانیں جاپانی، انگریزی، اور سادہ/روایتی چینی ہیں۔ (کورین ترجمہ ہدف زبان کے طور پر دستیاب رہتی ہے۔)
- خودکار ترجمہ کے لیے فی صفحہ ایک تصویر (صفحے کی مرکزی تصویر)۔ دیگر کا ترجمہ کرنے کے لیے رائٹ کلک → Send to استعمال کریں۔
- بڑے سیشن — ایک سیشن میں درجنوں تصاویر کا ترجمہ کرنے سے براؤزر کریش ہو سکتا ہے۔ ایسا ہونے پر ترتیبات میں صفحہ کیش صاف کریں۔
- Firefox — ماڈل بیک گراؤنڈ صفحے میں چلتے ہیں (offscreen دستاویزات کے بغیر)، باقی سب کے ساتھ میموری شیئر کرتے ہوئے۔ "no available backend found" نظر آئے تو براؤزر دوبارہ شروع کریں۔
- Firefox Chrome سے سست ہے — Firefox ایکسٹینشن ملٹی تھریڈنگ کے لیے مشترکہ میموری (SharedArrayBuffer) استعمال نہیں کر سکتے، اس لیے ماڈل ایک ہی CPU تھریڈ پر چلتا ہے۔ یہ ایکسٹینشن کی غلطی نہیں، Firefox پلیٹ فارم کی حد ہے ([Mozilla bug 1673477](https://bugzilla.mozilla.org/show_bug.cgi?id=1673477))۔
- Google Translate غیر سرکاری مفت اینڈ پوائنٹ استعمال کرتا ہے اور ریٹ محدود ہو سکتا ہے۔
