# comic-translate-4-free

**Language:** [English](README.md) · [हिन्दी](README.hi.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md) · [Bahasa Indonesia](README.id.md) · [اردو](README.ur.md) · [Deutsch](README.de.md)

ब्राउज़र में ही मंगा/कॉमिक पेज का अनुवाद करें। पूरी पाइपलाइन लोकल चलती है:
बबल/टेक्स्ट डिटेक्शन (RT-DETR-v2), OCR (जापानी/अंग्रेज़ी/चीनी के लिए Baberu),
LaMa इनपेंटिंग से टेक्स्ट हटाना, अनुवाद (Google / Azure / लोकल LLM), और मूल
स्पीच बबल में लपेटकर दोबारा रेंडर करना।

एक्सटेंशन का UI आपके ब्राउज़र की भाषा सेटिंग के अनुसार चलता है (अंग्रेज़ी, जापानी,
कोरियाई, सरलीकृत/पारंपरिक चीनी, हिन्दी, स्पेनिश, अरबी, फ्रेंच, बांग्ला, पुर्तगाली, रूसी, वियतनामी, इंडोनेशियाई, उर्दू, जर्मन)।

यह प्रोजेक्ट [ogkalu2/comic-translate](https://github.com/ogkalu2/comic-translate) से प्रेरित है।

## इंस्टॉल

**Chrome (सुझावित):**
[**Chrome वेब स्टोर**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj)
से इंस्टॉल करें — एक क्लिक, अपने आप अपडेट।

**मैन्युअल इंस्टॉल (Chrome):** ऊपर Releases से zip डाउनलोड करके अनज़िप करें,
फिर `chrome://extensions` → **Developer mode** चालू करें →
**Load unpacked** → अनज़िप किया फ़ोल्डर चुनें।

**Firefox:** `about:debugging#/runtime/this-firefox` → **Load Temporary
Add-on** → अनज़िप किए फ़ोल्डर को खोलकर `manifest.json` चुनें। (अस्थायी
ऐड-ऑन Firefox रीस्टार्ट तक रहते हैं। स्थायी इंस्टॉल के लिए बिल्ड
addons.mozilla.org पर साइन होना चाहिए। Firefox स्टैंडर्ड एडिशन के लिए साइन्ड
एक्सटेंशन पर काम चल रहा है।)

फिर Settings पेज से मॉडल एक बार डाउनलोड करें — एक
**Download all models** बटन से सब कुछ आ जाता है (डिटेक्टर, OCR मॉडल,
इनपेंटर, कुल ~350 MB)। ये ब्राउज़र (IndexedDB) में कैश रहते हैं और दोबारा
डाउनलोड नहीं होते। डाउनलोड के बाद हर फ़ाइल का बाइट साइज़ वेरिफ़ाई होता है;
कटी-फटी या गलत फ़ाइल पर ⚠ लग जाता है और दोबारा डाउनलोड की जा सकती है।

![Settings पेज से मॉडल डाउनलोड करना](docs/images/options-models.png)

## इस्तेमाल

1. **पहले साइट को अनुमति दें** — अनुवाद सिर्फ़ उन्हीं साइटों पर चलता है
   जिन्हें आप साफ़ तौर पर अनुमति देते हैं। एक्सटेंशन आइकन पर क्लिक करके
   **Allow this site** दबाएं (या Settings में होस्टनेम डालें, या हर जगह
   यह स्टेप छोड़ने के लिए **ALLOW ALL SITES** चालू करें)। यह पक्की शर्त है:
   पाइपलाइन कहीं और चलने से इनकार कर देती है।

   ![एक्सटेंशन पॉपअप](docs/images/popup.png)

2. अनुमत साइट पर मंगा पेज खोलें — पेज लोड होते ही अनुवाद अपने आप शुरू
   हो जाता है, बटन दबाने की ज़रूरत नहीं (Settings में "Auto-translate on page load"
   से इसे बंद/चालू कर सकते हैं)। हर साइट पर पहली बार Chrome एक बार की
   अनुमति मांगता है ताकि एक्सटेंशन पेज की इमेज पूरी रेज़ोल्यूशन पर डाउनलोड
   कर सके।
3. पेज के ऊपर-दाईं ओर स्टेटस पिल लाइव प्रोग्रेस दिखाती है
   (Capturing → Detecting → OCR → …)। पूरा होने पर पेज की अपनी तस्वीर
   अनूदित वर्शन से वहीं बदल जाती है — मूल टेक्स्ट इनपेंट करके हटाया हुआ,
   अनुवाद बबल में वापस रेंडर किया हुआ।

पेज की मुख्य इमेज के बजाय किसी एक खास तस्वीर का अनुवाद करने के लिए,
उस पर राइट-क्लिक करके **Send to comic-translate-4-free** चुनें। इससे
वही इमेज पाइपलाइन में जाती है — चाहे वह न्यूनतम इमेज साइज़ से छोटी हो —
और फिर भी वहीं बदल जाती है। यह मेन्यू आइटम सिर्फ़ अनुमत साइटों पर दिखता है।

अगर इमेज सर्वर डाउनलोड से इनकार कर दे (HTTP 403, जैसे Cloudflare बॉट
प्रोटेक्शन), तो एक्सटेंशन इमेज को बैकग्राउंड टैब में अपने आप खोल लेता है —
वहां वह same-origin होती है, इसलिए तस्वीर बिना डाउनलोड सीधे पढ़ ली जाती है —
उसका अनुवाद करता है, टैब बंद कर देता है, और आपके पेज पर तस्वीर वहीं बदल
देता है।

   ![राइट-क्लिक मेन्यू](docs/images/right-click.png)

पाइपलाइन का इनपुट पेज की सबसे बड़ी इमेज होती है, जो न्यूनतम इमेज साइज़
सेटिंग (डिफ़ॉल्ट 500px) से तय होती है: छोटी तस्वीरें साफ़ एरर के साथ छोड़
दी जाती हैं। एक्सटेंशन पेज की अपनी इमेज सीधे पढ़ता है — वह कभी वेबपेज का
स्क्रीनशॉट नहीं लेता।

**पेज कैश:** उसी ब्राउज़र सेशन में दोबारा खोले गए पेज अस्थायी ऑन-डिस्क कैश
से तुरंत लोड होते हैं (एक सेशन में 10~40 इमेज का अनुवाद करने से ब्राउज़र
क्रैश हो सकता है, जिससे कैश की सारी इमेज चली जाती हैं। कृपया कैश मैन्युअल
साफ़ करना याद रखें)। ब्राउज़र बंद होने पर कैश अपने आप साफ़ हो जाता है,
और incognito विंडो में कभी इस्तेमाल नहीं होता।

**Settings** (आइकन पर क्लिक → Settings): साइट एक्सेस, पेज लोड पर
ऑटो-अनुवाद, स्रोत भाषा (**Auto-detect** सहित, जो OCR किए टेक्स्ट से
जापानी / अंग्रेज़ी / सरलीकृत / पारंपरिक चीनी पहचानती है)
और लक्ष्य भाषा, अनुवाद इंजन (Google मुफ़्त / Azure
Translator / LM Studio), Azure और LM Studio के कनेक्शन-टेस्ट बटन,
डिटेक्शन थ्रेशोल्ड, न्यूनतम इमेज साइज़ (डिफ़ॉल्ट 500px — छोटे कैप्चर छोड़
दिए जाते हैं), फ़ॉन्ट साइज़, डीबग मोड, और अनूदित-पेज कैश कंट्रोल।

![Settings पेज](docs/images/options.png)

## इस प्रोजेक्ट को सपोर्ट करें

अगर यह एक्सटेंशन आपके काम का है, तो इसके विकास में मदद करें:

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/S5X627XJQW)

### Microsoft Azure अकाउंट के लिए अप्लाई करें

1. Microsoft/hotmail/Azure अकाउंट बनाएं/साइन इन करें
2. Azure सब्सक्रिप्शन बनाएं
3. Azure Translator रिसोर्स बनाएं
4. F0 (Free) प्राइसिंग टियर चुनें
5. Resource Management → Keys and Endpoint → **KEY 1** और **Location/Region** कॉपी करें

Microsoft का कहना है कि Translator F0 फ़्री टियर 2 मिलियन कैरेक्टर/माह है और एक्सपायर नहीं होता।

### LM Studio

LM Studio को लोकल सर्वर चालू करके चलाएं (डिफ़ॉल्ट
`http://127.0.0.1:1234`)। Settings में अनुवाद इंजन के तौर पर
**LM Studio (local server)** चुनें, सर्वर URL और API फ़्लेवर सेट करें —
**LM Studio REST API v1** (`/api/v1/chat` पर पोस्ट करता है) या
**OpenAI-compatible** (`/v1/chat/completions` पर पोस्ट करता है) — फिर
वेरिफ़ाई के लिए **Check LM Studio connection** दबाएं। लोडेड मॉडल अपने आप
पहचानकर याद रखा जाता है, इसलिए मॉडल-नेम भरने वाला कोई फ़ील्ड नहीं है।

## सोर्स से बिल्ड करें

कोई बंडलर नहीं, कोई npm install नहीं — सोर्स ही एक्सटेंशन है। ज़रूरतें:
`bash`, `python3`, `rsync`, `zip`, और `node` (सिर्फ़ सिंटैक्स चेक के लिए)।

```bash
git clone https://github.com/jameslee0623/comic-translate-4-free.git
cd comic-translate-4-free
./build.sh
```

इससे `dist/` में तीन zip बनती हैं (सुविधा के लिए मिली-जुली zip की एक कॉपी भी):

- `comic-translate-4-free-v<version>-<build>.zip` — मिली-जुली, `chrome/` और
  `firefox/` साथ-साथ, अनपैक्ड लोड (Chrome) या अस्थायी
  ऐड-ऑन (Firefox) के लिए तैयार, ऊपर "Install" के अनुसार
- `comic-translate-4-free-v<version>-<build>-chrome.zip` — सिर्फ़ Chrome बिल्ड,
  स्टोर-सबमिशन लेआउट में
- `comic-translate-4-free-v<version>-<build>-firefox.zip` — सिर्फ़ Firefox बिल्ड,
  स्टोर-सबमिशन लेआउट में

`<build>` स्टैम्प `src/shared/version.js` के `BUILD` const से आता है
(पॉपअप और सेटिंग्स पेज के फ़ुटर में दिखता है, पेज-कैश की में बेक्ड है)।
बिल्ड करने से पहले इसे बढ़ा दें अगर फ़ाइलनेम और UI
फ़ुटर में यूनिक स्टैम्प चाहिए — वरना आपका बिल्ड उसी स्टैम्प वाले रिलीज़्ड
बिल्ड से अलग नहीं पहचाना जाएगा।

हर पेज पर एक्सटेंशन एक ही बैच्ड रिक्वेस्ट भेजता है:

```
POST {server}/chat/completions
{
  "messages": [
    { "role": "user",
      "content": "Translate the following 9 text(s) from Japanese to Chinese (Traditional):\n[\"…\",\"…\"]" }
  ],
  "temperature": 0,
  "texts": ["…", "…"],
  "target": "zh-TW",
  "source": "ja"
}
```

मॉडल से अनूदित स्ट्रिंग्स का JSON ऐरे जवाब में अपेक्षित है —
हर इनपुट टेक्स्ट के लिए एक, उसी क्रम में। लंबे जवाब के अंदर नंगा `[...]`
स्वीकार है; एक अनुवाद प्रति लाइन आखिरी उपाय वाला फ़ॉलबैक है।

## डीबग मोड

Settings में **Debug mode** चालू करें और हर पाइपलाइन स्टेज का आउटपुट
साइड-पैनल इंस्पेक्टर में दिखेगा: कैप्चर की गई इमेज, डिटेक्शन बॉक्स, टेक्स्ट
ब्लॉक, OCR क्रॉप + रीडिंग, इनपेंट मास्क, इनपेंट किया पेज, और अनुवाद।

## आर्किटेक्चर

```
popup / settings (src/ui)
      │ chrome.runtime messages
      ▼
background — ऑर्केस्ट्रेशन, कैप्चर, ब्लॉक, मास्क, अनुवाद API,
             डीबग एमिशन
  ├─ Chrome: service worker + offscreen document (src/offscreen) जो
  │  सारे onnxruntime-web सेशन होस्ट करता है (डाउनलोड वहीं चलते हैं ताकि
  │  197 MB फ़ेच SW शटडाउन से बच जाए)
  └─ Firefox: background page (src/background/background.html) जो वही
     सेशन इन-प्रोसेस होस्ट करती है (Firefox में offscreen document नहीं हैं)
└── content script (src/content) — ओवरले कैनवास + टेक्स्ट रेंडरर + डीबग पैनल
```

मॉडल (Hugging Face, मांग पर डाउनलोड):
- `ogkalu/comic-text-and-bubble-detector` → `detector-v4-s_int8.onnx`
- `genshiai-daichi/baberu-ocr` → `vision_int4.onnx`, `decoder_prefill_int8.onnx`,
  `decoder_step_int8.onnx` (जापानी, अंग्रेज़ी, सरलीकृत/पारंपरिक चीनी)
- `ogkalu/lama-manga-onnx-dynamic` → `lama-manga-dynamic.onnx`

पाइपलाइन स्टेज: capture → detect → blocks → OCR → mask → inpaint →
translate → render। डिटेक्शन 640×640 पर चलता है; कैप्चर एरिया से स्केल होता
है (6.5 MP बजट) ताकि लंबी स्ट्रिप पूरी रेज़ोल्यूशन रखें, और 4:1 से ज़्यादा
एक्सट्रीम आस्पेक्ट वाले पेज ओवरलैपिंग 2:1 सेगमेंट में प्रोसेस होते हैं।

**Chrome बनाम Firefox पाइपलाइन:** दोनों बिल्ड OCR के बाद translate को
mask/inpaint के साथ पैरेलल चलाते हैं। Chrome इसे Promise.all से करता है —
ML सेशन offscreen document में अपने थ्रेड पर रहते हैं, इसलिए स्टेज सच में
ओवरलैप होते हैं। Firefox अनुवाद को Web Worker (अपने थ्रेड) पर चलाता है जबकि
mask → inpaint मेन थ्रेड पर चलता है — WASM इनपेंट के मेन थ्रेड हॉग करने पर
भी वर्कर का नेटवर्क I/O ब्लॉक नहीं होता।

## ज्ञात सीमाएं

  अंग्रेज़ी, और सरलीकृत/पारंपरिक चीनी तक सीमित हैं।

  पेज की किसी और तस्वीर का अनुवाद करने के लिए उस पर राइट-क्लिक करके
  **Send to comic-translate-4-free** चुनें।
- कुछ इमेज होस्ट ऑटोमेटेड डाउनलोड ब्लॉक करते हैं (HTTP 403, जैसे Cloudflare बॉट
  प्रोटेक्शन) भले ही पेज खुद इमेज ठीक लोड करता हो।
  राइट-क्लिक वाला **Send to comic-translate-4-free** बैकग्राउंड
  टैब से इसे बायपास कर देता है; ऐसी साइटों पर ऑटो-अनुवाद 403 एरर दे सकता है।
  यह ब्लॉकिंग रुक-रुक कर हो सकती है।
- Firefox: AI मॉडल ब्राउज़र के बैकग्राउंड पेज के अंदर चलते हैं (Firefox में
  offscreen document नहीं हैं), बाकी सबके साथ मेमोरी शेयर करते हुए। बहुत बड़े
  पेज या लंबे सेशन पर इंजन की मेमोरी खत्म हो सकती है और
  "no available backend found" रिपोर्ट कर सकता है। ब्राउज़र रीस्टार्ट करने से मेमोरी खाली होती है; Chrome
  अप्रभावित है क्योंकि वह मॉडल अलग प्रोसेस में चलाता है।
- Chrome: एक सेशन में दर्जनों इमेज का अनुवाद करने से ब्राउज़र क्रैश हो
  सकता है (लगभग 35 कैश्ड इमेज पर देखा गया)।
- पेज कैश सेशन-स्कोप्ड है: ब्राउज़र स्टार्ट होने पर वाइप हो जाता है, इसलिए
  रीस्टार्ट के बाद (क्रैश के बाद समेत) दोबारा भेजी इमेज कैश हिट करने के बजाय
  पूरी पाइपलाइन चलाती हैं।
- Google अनुवाद इंजन अनऑफ़िशियल `translate.googleapis.com`
  एंडपॉइंट इस्तेमाल करता है और रेट-लिमिट हो सकता है।
- वर्टिकल टेक्स्ट लंबे CJK ब्लॉक के लिए रेंडर होता है; बबल के बाहर SFX / टेक्स्ट
  अपना टेक्स्ट बॉक्स इस्तेमाल करता है।
