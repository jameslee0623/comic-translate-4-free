    Languages

    Translating engine

    Azure key/region are stored only in this browser's extension storage. LM Studio must be running with its OpenAI-compatible server enabled (default http://127.0.0.1:1234).

    Detection & rendering

    Pages smaller than the minimum image size are skipped. The render font size is auto-estimated from the original text on the page (capped by the maximum above).

    Automation

    When on, allowed pages start translating automatically as soon as they finish loading — no button click needed. (Tip: allow a site from the popup so the extension gets permission to read its images.)

    Debug

    Shows every pipeline stage's output in a side panel so each stage can be checked.

    Models

    Models are downloaded from Hugging Face once and cached in the browser (IndexedDB).

    Translated page cache

    Pages you revisit in this browser session load instantly from a temporary cache. The cache is cleared automatically when the browser closes.

    This extension is free and open source. If it saves you time, you can support its ongoing development.
