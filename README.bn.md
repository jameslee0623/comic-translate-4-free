# comic-translate-4-free

**Language:** [English](README.md) · [हिन्दी](README.hi.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [বাংলা](README.bn.md)

ব্রাউজারেই মাঙ্গা/কমিক পেজ অনুবাদ করুন। পুরো পাইপলাইন লোকালি চলে:
বাবল/টেক্সট ডিটেকশন (RT-DETR-v2), OCR (জাপানি/ইংরেজি/চীনার জন্য Baberu),
LaMa ইনপেইন্টিংয়ের মাধ্যমে লেখা মুছে ফেলা, অনুবাদ (Google / Azure / লোকাল LLM),
এবং মূল বক্তৃতা বাবলগুলোতে মুড়িয়ে পুনরায় রেন্ডার করা।

এক্সটেনশনের UI আপনার ব্রাউজারের ভাষা সেটিং অনুসরণ করে (ইংরেজি, জাপানি,
কোরিয়ান, সরলীকৃত/ঐতিহ্যবাহী চীনা, হিন্দি, স্প্যানিশ, আরবি, ফরাসি, বাংলা)।

এই প্রকল্পটি [ogkalu2/comic-translate](https://github.com/ogkalu2/comic-translate) থেকে অনুপ্রাণিত।

## ডাউনলোড (বিল্ড ছাড়াই)

**Chrome / Edge / Brave — Chrome ওয়েব স্টোর থেকে ইনস্টল করুন:**

[**Chrome ওয়েব স্টোর থেকে comic-translate-4-free ইনস্টল করুন**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj)

অথবা
[**Releases**](https://github.com/jameslee0623/comic-translate-4-free/releases)
পেজ থেকে সর্বশেষ রিলিজটি নিন — প্রতিটি রিলিজ CI দ্বারা স্বয়ংক্রিয়ভাবে বিল্ড হয়।
আপনার ব্রাউজারের জন্য zip ডাউনলোড করুন:

- `comic-translate-4-free-v<version>-<build>-chrome.zip` → Chrome / Edge / Brave
- `comic-translate-4-free-v<version>-<build>-firefox.zip` → Firefox

(একটি সম্মিলিত `comic-translate-4-free-v<version>-<build>.zip`-ও আছে
যাতে `chrome/` ও `firefox/` পাশাপাশি রয়েছে, একসাথে দুটোই চাইলে।)
রেপো ক্লোন বা `build.sh` চালানোর দরকার নেই।

## ইনস্টল

**Chrome (প্রস্তাবিত):**
[**Chrome ওয়েব স্টোর**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj)
থেকে ইনস্টল করুন — এক ক্লিক, স্বয়ংক্রিয় আপডেট।

**ম্যানুয়াল ইনস্টল (Chrome):** উপরের Releases থেকে zip ডাউনলোড করে আনজিপ করুন,
তারপর `chrome://extensions` → **Developer mode** চালু করুন →
**Load unpacked** → আনজিপ করা ফোল্ডারটি বেছে নিন।

**Firefox:** `about:debugging#/runtime/this-firefox` → **Load Temporary
Add-on** → আনজিপ করা ফোল্ডারটি খুলে `manifest.json` বেছে নিন। (অস্থায়ী
অ্যাড-অন Firefox পুনরায় চালু হওয়া পর্যন্ত থাকে। স্থায়ী ইনস্টলের জন্য
addons.mozilla.org-এ বিল্ডটি সাইন করা আবশ্যক। Firefox স্ট্যান্ডার্ড সংস্করণের জন্য সাইন করা এক্সটেনশনের কাজ চলছে।)

তারপর Settings পেজ থেকে একবার মডেলগুলো ডাউনলোড করুন — একটি
**Download all models** বাটন সবকিছু নিয়ে আসে (ডিটেক্টর, OCR মডেল,
ইনপেইন্টার, মোট ~350 MB)। এগুলো ব্রাউজারে (IndexedDB) ক্যাশ হয় এবং আর
পুনরায় ডাউনলোড হয় না। ডাউনলোডের পর প্রতিটি ফাইলের বাইট সাইজ যাচাই করা হয়;
কাটা বা ভুল ফাইলে ⚠ চিহ্ন দেখায় এবং পুনরায় ডাউনলোড করা যায়।

## ব্যবহার

1. **আগে সাইটটিকে অনুমতি দিন** — অনুবাদ শুধুমাত্র আপনার স্পষ্টভাবে
   অনুমোদিত সাইটগুলোতে চলে। এক্সটেনশন আইকনে ক্লিক করে **Allow this site**
   চাপুন (অথবা Settings-এ হোস্টনেম যোগ করুন, অথবা সর্বত্র এই
   ধাপ এড়াতে **ALLOW ALL SITES** চালু করুন)। এটি একটি কঠোর গেট: পাইপলাইন
   অন্য কোথাও চলতে অস্বীকার করে।

   ![The extension popup](docs/images/popup.png)

2. অনুমোদিত সাইটে একটি মাঙ্গা পেজ খুলুন — পেজ লোড শেষ হওয়ার সাথে সাথে
   এটি স্বয়ংক্রিয়ভাবে অনুবাদ শুরু করে, কোনো বাটনে ক্লিক করতে
   হয় না (Settings-এ "Auto-translate on page load"-এর অধীনে টগল করা যায়)।
   প্রতি সাইটে প্রথম ব্যবহারে, এক্সটেনশন যাতে পেজের ছবি পূর্ণ রেজোলিউশনে ডাউনলোড করতে পারে সেজন্য Chrome একবারের অনুমতি চায়।
3. পেজের উপরে-ডানে একটি স্ট্যাটাস পিল লাইভ অগ্রগতি দেখায়
   (Capturing → Detecting → OCR → …)। শেষ হলে, পেজের নিজের ছবিটি
   অনূদিত সংস্করণ দিয়ে জায়গাতেই প্রতিস্থাপিত হয় — মূল লেখা ইনপেইন্ট করে
   মুছে ফেলা হয়, অনুবাদ বাবলগুলোতে ফিরিয়ে রেন্ডার করা হয়।

পেজের মূল ছবির পরিবর্তে একটি নির্দিষ্ট ছবি অনুবাদ করতে,
তাতে রাইট-ক্লিক করে **Send to comic-translate-4-free** বেছে নিন। এটি
সেই নির্দিষ্ট ছবিটিকে পাইপলাইনে পাঠায় — ন্যূনতম ছবির মাপের চেয়ে ছোট হলেও —
এবং তবুও জায়গাতেই প্রতিস্থাপন করে। মেনু আইটেমটি শুধুমাত্র আপনার অনুমোদিত
সাইটগুলোতে দেখা যায়।

ছবির সার্ভার ডাউনলোড প্রত্যাখ্যান করলে (HTTP 403, যেমন Cloudflare বট
সুরক্ষা), এক্সটেনশনটি স্বয়ংক্রিয়ভাবে ছবিটি একটি ব্যাকগ্রাউন্ড
ট্যাবে খোলে — সেখানে এটি same-origin, তাই ছবিটি ডাউনলোড ছাড়াই সরাসরি পড়া হয় —
অনুবাদ করে, ট্যাবটি বন্ধ করে, এবং আপনার পেজে ছবিটি জায়গাতেই প্রতিস্থাপন করে।

   ![The right-click menu](docs/images/right-click.png)

পাইপলাইনের ইনপুট হলো পেজের সবচেয়ে বড় ছবি, ন্যূনতম ছবির মাপের সেটিং দ্বারা নিয়ন্ত্রিত (ডিফল্ট 500px): ছোট ছবিগুলো স্পষ্ট ত্রুটি সহ এড়িয়ে যাওয়া হয়। এক্সটেনশনটি পেজের নিজের ছবি সরাসরি পড়ে — এটি কখনো ওয়েবপেজের স্ক্রিনশট নেয় না।

**পেজ ক্যাশ:** একই ব্রাউজার সেশনে আপনি যে পেজগুলো আবার দেখেন সেগুলো অস্থায়ী অন-ডিস্ক ক্যাশ থেকে তাৎক্ষণিক লোড হয় (এক সেশনে 10~40টি ছবি অনুবাদ করলে ব্রাউজার ক্র্যাশ করতে পারে, ক্যাশের সব ছবি হারিয়ে যায়। ম্যানুয়ালি ক্যাশ মুছতে ভুলবেন না)। ব্রাউজার বন্ধ হলে ক্যাশ স্বয়ংক্রিয়ভাবে মুছে যায়, এবং ছদ্মবেশী (incognito) উইন্ডোতে কখনো ব্যবহার হয় না।

**Settings** (আইকনে ক্লিক → Settings): সাইট অ্যাক্সেস, পেজ লোডে স্বয়ং-অনুবাদ, উৎস ভাষা (**Auto-detect** সহ, যা OCR করা লেখা থেকে জাপানি / ইংরেজি / সরলীকৃত / ঐতিহ্যবাহী চীনা শনাক্ত করে) ও লক্ষ্য ভাষা, অনুবাদ ইঞ্জিন (Google ফ্রি / Azure Translator / LM Studio), Azure ও LM Studio-এর জন্য সংযোগ-পরীক্ষা বাটন, ডিটেকশন থ্রেশহোল্ড, ন্যূনতম ছবির মাপ (ডিফল্ট 500px — ছোট ক্যাপচার এড়িয়ে যাওয়া হয়), ফন্টের মাপ, ডিবাগ মোড, এবং অনূদিত-পেজ ক্যাশ নিয়ন্ত্রণ।

## এই প্রকল্পকে সমর্থন করুন

এই এক্সটেনশনটি আপনার কাজে লাগলে, এর উন্নয়নে সহায়তা করার কথা ভাবুন:

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/S5X627XJQW)

### Microsoft Azure অ্যাকাউন্টের জন্য আবেদন করুন

1. একটি Microsoft/hotmail/Azure অ্যাকাউন্ট তৈরি/সাইন ইন করুন
2. একটি Azure সাবস্ক্রিপশন তৈরি করুন
3. একটি Azure Translator রিসোর্স তৈরি করুন
4. F0 (Free) মূল্য স্তর বেছে নিন
5. Resource Management → Keys and Endpoint → **KEY 1** ও **Location/Region** কপি করুন

Microsoft বর্তমানে বলছে Translator F0 ফ্রি টায়ার মাসে 20 লাখ অক্ষর এবং এর মেয়াদ শেষ হয় না।

### LM Studio

LM Studio চালান এর লোকাল সার্ভার চালু রেখে (ডিফল্ট
`http://127.0.0.1:1234`)। Settings-এ অনুবাদ ইঞ্জিন হিসেবে **LM Studio (local server)** বেছে নিন, সার্ভার URL ও API ফ্লেভার সেট করুন — **LM Studio REST API v1** (`/api/v1/chat`-এ পোস্ট করে) অথবা **OpenAI-compatible** (`/v1/chat/completions`-এ পোস্ট করে) — তারপর যাচাই করতে **Check LM Studio connection** চাপুন। লোড করা মডেল স্বয়ংক্রিয়ভাবে শনাক্ত হয়ে মনে রাখা হয়, তাই মডেল-নামের কোনো ফিল্ড পূরণ করতে হয় না।

## সোর্স থেকে বিল্ড করুন

বান্ডলার নেই, npm install নেই — সোর্সই এক্সটেনশন। প্রয়োজন:
`bash`, `python3`, `rsync`, `zip`, এবং `node` (শুধু সিনট্যাক্স পরীক্ষার জন্য)।

```bash
git clone https://github.com/jameslee0623/comic-translate-4-free.git
cd comic-translate-4-free
./build.sh
```

এটি `dist/`-এ তিনটি zip লেখে (সুবিধার জন্য সম্মিলিত zip-এর একটি কপি সহ):

- `comic-translate-4-free-v<version>-<build>.zip` — সম্মিলিত, `chrome/` ও
  `firefox/` পাশাপাশি, আনপ্যাকড লোডের জন্য প্রস্তুত (Chrome) বা অস্থায়ী
  অ্যাড-অন হিসেবে (Firefox), উপরের "Install" অনুযায়ী
- `comic-translate-4-free-v<version>-<build>-chrome.zip` — শুধু Chrome বিল্ড,
  স্টোর-সাবমিশন লেআউটে
- `comic-translate-4-free-v<version>-<build>-firefox.zip` — শুধু Firefox বিল্ড,
  স্টোর-সাবমিশন লেআউটে

`<build>` স্ট্যাম্পটি `src/shared/version.js`-এর `BUILD` const থেকে আসে
(পপআপ ও সেটিংস পেজের ফুটারে দেখানো হয়, পেজ-ক্যাশ কী-তে বেক করা থাকে)।
ফাইলের নাম ও UI ফুটারে অনন্য স্ট্যাম্প চাইলে বিল্ডের আগে এটি বাড়ান —
নইলে একই স্ট্যাম্পের রিলিজ করা বিল্ড থেকে আপনার বিল্ড আলাদা করা যাবে না।

প্রতি পেজে এক্সটেনশনটি একটি ব্যাচড রিকোয়েস্ট পাঠায়:

```
POST {server}/chat/completions
{
  "messages": [
    { "role": "user",
      "content": "Translate the following 9 text(s) from Japanese to Chinese (Traditional):\n[\"…\",\"…\"]" }
  ],
  "temperature": 0,
  "texts": ["…", "…"],
  "target": "zh-TW",
  "source": "ja"
}
```

মডেলটি অনূদিত স্ট্রিংয়ের একটি JSON অ্যারে দিয়ে উত্তর দেবে বলে আশা করা হয় —
প্রতি ইনপুট লেখার জন্য একটি, একই ক্রমে। দীর্ঘ উত্তরের ভেতরে খালি `[...]` গ্রহণযোগ্য;
প্রতি লাইনে একটি অনুবাদ হলো শেষ-অবলম্বন ফলব্যাক।

## ডিবাগ মোড

Settings-এ **Debug mode** চালু করুন এবং পাইপলাইনের প্রতিটি ধাপের আউটপুট একটি
সাইড-প্যানেল ইনস্পেক্টরে দেখা যাবে: ক্যাপচার করা ছবি, ডিটেকশন বক্স, টেক্সট ব্লক, OCR
ক্রপ + রিডিং, ইনপেইন্ট মাস্ক, ইনপেইন্ট করা পেজ, এবং অনুবাদ।

## আর্কিটেকচার

```
popup / settings (src/ui)
      │ chrome.runtime messages
      ▼
background — অর্কেস্ট্রেশন, ক্যাপচার, ব্লক, মাস্ক, অনুবাদ API,
             ডিবাগ নির্গমন
  ├─ Chrome: service worker + offscreen document (src/offscreen) হোস্ট করে
  │  সব onnxruntime-web সেশন (ডাউনলোড সেখানে চলে যাতে 197 MB ফেচ
  │  SW শাটডাউন টিকে থাকে)
  └─ Firefox: background page (src/background/background.html) একই সেশনগুলো
     ইন-প্রসেসে হোস্ট করে (Firefox-এ offscreen document নেই)
└── content script (src/content) — ওভারলে ক্যানভাস + টেক্সট রেন্ডারার + ডিবাগ প্যানেল
```

মডেল (Hugging Face, চাহিদা অনুযায়ী ডাউনলোড হয়):
- `ogkalu/comic-text-and-bubble-detector` → `detector-v4-s_int8.onnx`
- `genshiai-daichi/baberu-ocr` → `vision_int4.onnx`, `decoder_prefill_int8.onnx`,
  `decoder_step_int8.onnx` (জাপানি, ইংরেজি, সরলীকৃত/ঐতিহ্যবাহী চীনা)
- `ogkalu/lama-manga-onnx-dynamic` → `lama-manga-dynamic.onnx`

পাইপলাইনের ধাপ: capture → detect → blocks → OCR → mask → inpaint →
translate → render। ডিটেকশন 640×640-এ চলে; ক্যাপচার এরিয়া অনুযায়ী স্কেল হয়
(6.5 MP বাজেট) যাতে লম্বা স্ট্রিপ পূর্ণ রেজোলিউশন ধরে রাখে, এবং 4:1-এর চেয়ে চরম
অ্যাসপেক্টের পেজগুলো ওভারল্যাপিং 2:1 সেগমেন্টে প্রসেস হয়।

**Chrome বনাম Firefox পাইপলাইন:** দুটো বিল্ডই OCR-এর পর translate-কে mask/inpaint-এর সাথে সমান্তরালে চালায়। Chrome Promise.all দিয়ে করে — ML সেশনগুলো offscreen document-এ নিজের থ্রেডে থাকে, তাই ধাপগুলো সত্যিই ওভারল্যাপ হয়। Firefox অনুবাদ Web Worker-এ (নিজের থ্রেডে) চালায় যেখানে mask → inpaint মূল থ্রেডে চলে — WASM ইনপেইন্ট মূল থ্রেড দখল করলেও worker-এর নেটওয়ার্ক I/O ব্লক হয় না।

## পরিচিত সীমাবদ্ধতা

- কোরিয়ানের জন্য এখনো ভালো OCR পাওয়া যায়নি — উৎস ভাষা জাপানি,
  ইংরেজি, ও সরলীকৃত/ঐতিহ্যবাহী চীনাতে সীমাবদ্ধ।
- স্বয়ং-অনুবাদ প্রতি পেজে একটি ছবি সামলায় (পেজের মূল ছবি)।
  পেজের অন্য কোনো ছবি অনুবাদ করতে, তাতে রাইট-ক্লিক করে
  **Send to comic-translate-4-free** বেছে নিন।
- কিছু ছবির হোস্ট স্বয়ংক্রিয় ডাউনলোড ব্লক করে (HTTP 403, যেমন Cloudflare বট
  সুরক্ষা) যদিও পেজ নিজে ছবিটি ঠিকমতো লোড করে।
  রাইট-ক্লিকের **Send to comic-translate-4-free** ব্যাকগ্রাউন্ড ট্যাবের মাধ্যমে এটি এড়ায়;
  এমন সাইটে স্বয়ং-অনুবাদ 403 ত্রুটি দিয়ে ব্যর্থ হতে পারে।
  এই ব্লকিং মাঝে মাঝে হতে পারে।
- Firefox: AI মডেলগুলো ব্রাউজারের ব্যাকগ্রাউন্ড পেজের ভেতরে চলে (Firefox-এ
  offscreen document নেই), বাকি সবকিছুর সাথে মেমরি ভাগ করে। খুব বড়
  পেজ বা দীর্ঘ সেশনে ইঞ্জিনের মেমরি শেষ হয়ে "no available backend found" রিপোর্ট করতে পারে। ব্রাউজার পুনরায় চালু করলে মেমরি মুক্ত হয়; Chrome
  প্রভাবিত হয় না কারণ এটি মডেলগুলো আলাদা প্রসেসে চালায়।
- Chrome: এক সেশনে ডজনখানেক ছবি অনুবাদ করলে ব্রাউজার ক্র্যাশ করতে পারে
  (প্রায় 35টি ক্যাশ করা ছবিতে দেখা গেছে)।
- পেজ ক্যাশ সেশন-স্কোপড: ব্রাউজার চালু হলে এটি মুছে যায়, তাই
  পুনরায় চালুর পর (ক্র্যাশের পর সহ) আবার পাঠানো ছবিগুলো ক্যাশে হিট না করে পূর্ণ
  পাইপলাইন চালায়।
- Google অনুবাদ ইঞ্জিন অনানুষ্ঠানিক `translate.googleapis.com`
  এন্ডপয়েন্ট ব্যবহার করে এবং রেট-লিমিটেড হতে পারে।
- লম্বা CJK ব্লকের জন্য উল্লম্ব লেখা রেন্ডার হয়; বাবলের বাইরের SFX / লেখা
  নিজস্ব টেক্সট বক্স ব্যবহার করে।
