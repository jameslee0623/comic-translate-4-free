নিজের ভাষায় মাঙ্গা পড়ুন — সরাসরি ব্রাউজারে।

comic-translate-4-free আপনি ব্রাউজ করার সময় মাঙ্গা ও কমিকের পাতা স্বয়ংক্রিয়ভাবে অনুবাদ করে। এটি জাপানি, ইংরেজি, সরলীকৃত ও প্রথাগত চীনা (স্বয়ং-শনাক্তকরণসহ) পড়তে পারে, এবং 114টি ভাষায় অনুবাদ করে। একটি পাতা খুলুন — অনুদিত সংস্করণটি মূল ছবির জায়গায় বসে যায় — আপনার ভাষায় পূর্ণ বক্তৃতা-বুদবুদসহ।

## ✨ বৈশিষ্ট্য

- **স্বয়ংক্রিয় অনুবাদ** — অনুমোদিত সাইটে একটি মাঙ্গা পাতা খুলুন, কোনো বোতামে ক্লিক না করেই অনুদিত সংস্করণ মূল জায়গায় হাজির হবে।
- **যেকোনো ছবিতে রাইট-ক্লিক** — নির্দিষ্ট একটি ছবি অনুবাদ করতে "Send to comic-translate-4-free" বেছে নিন, এমনকি সেটি ন্যূনতম আকারের চেয়ে ছোট হলেও।
- **114টি লক্ষ্য ভাষা** — Google Translate, Azure Translator অথবা আপনার নিজের লোকাল LM Studio সার্ভারের মাধ্যমে।
- **উৎস ভাষার স্বয়ং-শনাক্তকরণ** — OCR-কৃত টেক্সট থেকে জাপানি, ইংরেজি, সরলীকৃত/প্রথাগত চীনা স্বয়ংক্রিয়ভাবে শনাক্ত হয়।
- **লং-স্ট্রিপ / ওয়েবটুন সাপোর্ট** — লম্বা পাতাগুলো ওভারল্যাপিং অংশে ভাগ করে প্রসেস করা হয়, ফলে টেক্সট ঝাপসা হয় না।
- **16টি UI ভাষা** — এক্সটেনশনের ইন্টারফেস আপনার ব্রাউজারের ভাষা সেটিং অনুসরণ করে।

### 🔒 গোপনীয়তা

- **AI চলে আপনার মেশিনে।** বাবল শনাক্তকরণ, OCR ও ইনপেইন্টিং — সবই আপনার ব্রাউজারে WebAssembly-এর মাধ্যমে লোকালভাবে চলে। আপনার পাতা কখনো আপনার ডিভাইস ছেড়ে যায় না।
- **শুধু অনুদিত টেক্সটই পাঠানো হয়** — শুধুমাত্র নিষ্কাশিত স্ট্রিংগুলো আপনার বাছাই করা অনুবাদ সেবায় যায় (Google / Azure / আপনার লোকাল LM Studio)।
- **কোনো অ্যাকাউন্ট নয়, কোনো ট্র্যাকিং নয়, কোনো টেলিমেট্রি নয়।** সব সেটিং ও ক্যাশড মডেল আপনার ব্রাউজারের লোকাল স্টোরেজেই থাকে।

## 🚀 ইনস্টলেশন

**Chrome / Edge / Brave:**

[**Chrome Web Store থেকে ইনস্টল করুন**](https://chromewebstore.google.com/detail/pndooikgcenncdohfggodonniihplppj) — এক ক্লিকে, স্বয়ংক্রিয় আপডেটসহ।

**Firefox:** ফায়ারফক্স জিপটি [Releases](https://github.com/jameslee0623/comic-translate-4-free/releases) থেকে ডাউনলোড করুন, তারপর `about:debugging#/runtime/this-firefox` পেজে গিয়ে **Load Temporary Add-on** চাপুন → `manifest.json` নির্বাচন করুন। (Temporary add-on রিস্টার্টে আনলোড হয়ে যায়; স্বাক্ষরিত AMO তালিকা প্রক্রিয়াধীন।)

ইনস্টলের পর Settings পেজ খুলে **Download all models**-এ একবার ক্লিক করুন (~350 MB: ডিটেক্টর, OCR, ইনপেইন্টার)। এগুলো ব্রাউজারে ক্যাশ হয় এবং বাইট সাইজ দিয়ে যাচাই করা হয়।

![Settings পেজ থেকে মডেল ডাউনলোড](docs/images/options-models.png)

## 💡 কীভাবে ব্যবহার করবেন

1. **প্রথমে সাইটে অনুমতি দিন** — এক্সটেনশনের আইকনে ক্লিক করে **Allow this site** চাপুন (অথবা **ALLOW ALL SITES** চালু করুন)। শুধু যেখানে অনুমতি দিয়েছেন সেখানেই অনুবাদ চলে।

   ![পপআপ থেকে সাইটের অনুমতি দিন](docs/images/popup.png)

2. **মাঙ্গা পাতাটি রিলোড করুন** — পাতা লোড হলে এটি স্বয়ংক্রিয়ভাবে অনুবাদ শুরু করে। উপরে-ডানে একটি পিল লাইভ অগ্রগতি দেখায় (Capturing → Detecting → OCR → …)।
3. **হয়ে গেছে** — পাতার ছবিটি মূল জায়গায় অনুদিত সংস্করণ দিয়ে প্রতিস্থাপিত হয়।

**টিপস:**
- যেকোনো ছবিতে রাইট-ক্লিক করুন → শুধু সেই ছবিটি অনুবাদ করতে **Send to comic-translate-4-free**।

  ![ছবি পাঠাতে রাইট-ক্লিক করুন](docs/images/right-click.png)

- কোনো সাইট ডাউনলোড ব্লক করলে (HTTP 403), এক্সটেনশন ব্যাকগ্রাউন্ড ট্যাবের মাধ্যমে স্বয়ংক্রিয়ভাবে পুনরায় চেষ্টা করে।
- Settings-এ আপনার অনুবাদ ইঞ্জিন বেছে নিন: Google (ফ্রি, কোনো কী লাগে না), Azure Translator (নিচে কী-র জন্য আবেদন করুন — মাসে ২ মিলিয়ন অক্ষর ফ্রি), অথবা LM Studio (লোকাল সার্ভার)।
- পাইপলাইনের প্রতিটি ধাপ পরীক্ষা করতে Settings-এ **Debug mode** চালু করুন।

## 🔑 Microsoft Azure অ্যাকাউন্টের জন্য আবেদন

Azure Translator-কে অনুবাদ ইঞ্জিন হিসেবে ব্যবহার করতে:

1. একটি Microsoft/hotmail/Azure অ্যাকাউন্ট তৈরি করুন / সাইন ইন করুন
2. একটি Azure subscription তৈরি করুন
3. একটি Azure Translator রিসোর্স তৈরি করুন
4. F0 (Free) প্রাইসিং টিয়ার নির্বাচন করুন — মাসে ২ মিলিয়ন অক্ষর, মেয়াদ শেষ হয় না
5. Resource Management → Keys and Endpoint → **KEY 1** এবং **Location/Region** কপি করুন
6. এক্সটেনশনের Settings পেজে সেগুলো পেস্ট করুন

## ⚠️ জানা সমস্যা

- **এখনও কোরীয় OCR নেই** — উৎস ভাষা হলো জাপানি, ইংরেজি ও সরলীকৃত/প্রথাগত চীনা। (কোরীয় অনুবাদ-লক্ষ্য হিসেবে এখনও উপলব্ধ।)
- **অটো-ট্রান্সলেটে প্রতি পাতায় একটি ছবি** (পাতার মূল ছবি)। অন্যগুলো অনুবাদ করতে রাইট-ক্লিক → Send ব্যবহার করুন।
- **বড় সেশন** — এক সেশনে ডজনখানেক ছবি অনুবাদ করলে ব্রাউজার ক্র্যাশ করতে পারে। এমন হলে Settings থেকে পেজ ক্যাশ মুছে দিন।
- **Firefox** — মডেলগুলো ব্যাকগ্রাউন্ড পেজে চলে (কোনো offscreen document নেই), বাকি সবকিছুর সঙ্গে মেমরি ভাগ করে। "no available backend found" দেখলে ব্রাউজার রিস্টার্ট করুন।
- Google Translate অনানুষ্ঠানিক ফ্রি এন্ডপয়েন্ট ব্যবহার করে, তাই rate-limited হতে পারে।
