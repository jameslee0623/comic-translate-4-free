## Detailed description

📖 **Читайте мангу на своём языке — прямо в браузере.**

comic-translate-4-free автоматически переводит страницы комиксов и манги во время просмотра. Откройте страницу, и переведённая версия заменит оригинальное изображение на месте — облачка речи, заполненные вашим языком, и не нужно ничего нажимать.

**Как это работает**

1. Расширение находит каждую картинку на странице и фиксирует их.
2. Детектор ИИ на устройстве находит каждое облачко речи и блок текста.
3. Обученный на манге OCR читает текст (японский, английский, упрощённый и традиционный китайский — с автоматическим определением языка).
4. Оригинальный текст аккуратно удаляется с помощью ИИ-инпейнтинга.
5. Выбранный вами движок перевода возвращает результат обратно в облачка, подбирая размер по месту.

**Конфиденциальность прежде всего: ИИ работает на вашем компьютере**

Обнаружение облачков и OCR выполняются локально в вашем браузере через WebAssembly, а инпейнтинг работает на вашем GPU (с откатом на WebAssembly) — ваши страницы никогда не покидают ваше устройство. Только извлечённый текст отправляется в выбранный вами сервис перевода.

**Возможности**

- Автоматический перевод при загрузке страниц — без нажатия кнопок
- Переводит каждую картинку на странице (до 50 за запуск), а не только основное изображение
- Щёлкните правой кнопкой мыши по любому изображению → «Отправить в comic-translate-4-free», чтобы перевести его напрямую
- 114 целевых языков через Google Translate, Azure Translator или ваш собственный локальный сервер LM Studio
- Автоопределение исходного языка
- Поддержка длинных полос / вебтунов
- Работает на сайтах, блокирующих автоматические загрузки (через запасной вариант с фоновой вкладкой)
- Всплывающее окно и настройки с тёмной темой, управление доступом для каждого сайта
- Режим отладки показывает все этапы конвейера для устранения неполадок
