## Detailed description

**브라우저에서 바로 당신의 언어로 만화를 읽으세요.**

comic-translate-4-free는 브라우징하는 동안 만화와 코믹 페이지를 자동으로 번역합니다. 페이지를 열면 번역된 버전이 원본 이미지를 그 자리에서 대체합니다 — 당신의 언어로 가득 찬 말풍선, 클릭할 필요가 없습니다.

**작동 원리**

1. 확장 프로그램은 페이지의 모든 이미지를 찾아 캡처합니다.
2. 기기 내 AI 감지기가 모든 말풍선과 텍스트 블록을 찾아냅니다.
3. 만화로 학습한 OCR이 텍스트를 읽습니다(일본어, 영어, 간체/번체 중국어 — 자동 언어 감지 포함).
4. 원본 텍스트는 AI 인페인팅으로 깔끔하게 제거됩니다.
5. 선택한 번역 엔진이 결과를 말풍선에 다시 렌더링하고 크기에 맞게 조정합니다.

**개인정보 보호 우선: AI가 당신의 컴퓨터에서 실행됩니다**

말풍선 감지와 OCR은 브라우저 안에서 WebAssembly로 로컬 실행되고, 인페인팅은 GPU에서 실행됩니다(WebAssembly 폴백 포함) — 당신의 페이지는 절대 기기를 떠나지 않습니다. 추출된 텍스트만 당신이 선택한 번역 서비스로 전송됩니다.

**기능**

- 페이지 로드 시 자동 번역 — 버튼을 누를 필요가 없습니다
- 페이지의 모든 이미지(실행당 최대 50개)를 번역합니다, 메인 이미지만이 아닙니다
- 모든 이미지를 마우스 오른쪽 버튼으로 클릭 → "comic-translate-4-free로 보내기"를 선택하면 직접 번역할 수 있습니다
- Google Translate, Azure Translator 또는 자신의 로컬 LM Studio 서버를 통한 114개 대상 언어
- 원본 언어 자동 감지
- 긴 스트립 / 웹툰 지원
- 자동 다운로드를 차단하는 사이트에서도 작동합니다(백그라운드 탭 폴백을 통해)
- 다크 테마 팝업 및 설정, 사이트별 액세스 제어
- 디버그 모드는 문제 해결을 위해 파이프라인의 모든 단계를 보여줍니다
