## Detailed description

📖 **あなたの言語でマンガを読もう — ブラウザの中で。**

comic-translate-4-free はブラウジング中にマンガやコミックのページを自動で翻訳します。ページを開くと、翻訳版が元の画像とその場で置き換わります — 吹き出しがあなたの言語で埋まり、クリックするものは何もありません。

**仕組み**

1. 拡張機能はページ上のすべての画像を見つけてキャプチャします。
2. デバイス上の AI 検出器がすべての吹き出しとテキストブロックを見つけます。
3. マンガで学習した OCR がテキストを読み取ります（日本語、英語、簡体字/繁体字中国語 — 自動言語検出付き）。
4. 元のテキストは AI インペインティングできれいに除去されます。
5. あなたが選んだ翻訳エンジンが結果を吹き出しに描き戻し、サイズに合わせます。

**プライバシー第一：AI はあなたのコンピューター上で動作します**

吹き出し検出と OCR はブラウザ内で WebAssembly を使ってローカルに動作し、インペインティングは GPU 上で動作します（WebAssembly にフォールバック） — あなたのページがデバイスから出ることは決してありません。抽出されたテキストだけが、あなたが選んだ翻訳サービスに送られます。

**機能**

- ページ読み込み時の自動翻訳 — ボタンを押す必要はありません
- ページ上のすべての画像を翻訳します（1 回の実行で最大 50 枚まで）、メイン画像だけではありません
- 任意の画像を右クリック → 「comic-translate-4-free に送信」で直接翻訳
- Google Translate、Azure Translator、または自分のローカル LM Studio サーバーで 114 の対象言語に対応
- ソース言語の自動検出
- 縦長ストリップ / ウェブトゥーン対応
- 自動ダウンロードをブロックするサイトでも動作します（バックグラウンドタブ経由のフォールバック）
- ダークテーマのポップアップと設定、サイトごとのアクセス制御
- デバッグモードはトラブルシューティングのためにパイプラインのすべての段階を表示します
